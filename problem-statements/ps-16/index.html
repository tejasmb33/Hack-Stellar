PS–16

Returns That Never Go Home: Intelligent E-Commerce Return Management System

DOMAINSAI / E-Commerce / Logistics

Problem Description

Returned e-commerce products are generally transported back to central warehouses, even when nearby customers are waiting for the same products. This increases transportation costs and delivery time.

Your Challenge

Develop an intelligent return management system that determines whether returned products should go to a warehouse, nearby hub or directly to another customer based on product condition, nearby orders, delivery requirements and potential fraud.
