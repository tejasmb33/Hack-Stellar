Original cosmic environment

The black-hole environment is rendered live using a three-dimensional gravitational ray integrator, a procedural accretion disk, perspective stars and orbiting dust. It uses no movie frames, background image or video. The lensing is an artistic real-time approximation, not a scientific measurement or full Kerr simulation.

Open-source tools and type

Three.js r180, MIT license. Space Grotesk, Inter and Josefin Sans, SIL Open Font License. Local license copies are included with the project.
